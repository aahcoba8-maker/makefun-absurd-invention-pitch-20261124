One sentence pitching an absurd invention for a tiny everyday annoyance:
the toast that always lands butter-side down.

## The pitch

> A toaster that launches your toast with a tiny parachute so it never lands butter-side down, then bills you for air traffic control.

## How it works

`main.py` (stdlib only) writes the sentence to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (fallback `/output`, then the script directory).
